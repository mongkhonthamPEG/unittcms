# Commands

Following commands are useful for unittcms development.
(Setting up a server directly from source, please refer to the following link: [Running UnitTCMS from Source](../getstarted/from-source.md))

## Frontend

| commands       | description                          |
| -------------- | ------------------------------------- |
| `pnpm run dev` | Start frontend server with dev mode |

## Backend

| commands            | description                         |
| ------------------- | ------------------------------------ |
| `pnpm run dev`      | Start backend server with dev mode |
| `pnpm run migrate`  | Set up database                    |
| `pnpm run drop`     | Drop tables                        |
| `pnpm run seed`     | Insert seed data                   |
